## 1. Architectural Summary & Scope

The **VaaniDoc 2.0 Laboratory Module** is officially frozen. It is a streamlined, clinical diagnostic portal tailored specifically for accredited laboratories and pathologists to process CBC orders created during VaaniDoc consultations.

### Core Invariants (Locked)
1. **Bounded Access Scope:** During an active access grant, the laboratory receives **strictly four identity fields** (`Name`, `Age/Date of Birth`, `Gender`, `Phone Number`) and the diagnostic order (`CBC`). No prior consultation notes, historical records, or timeline data are accessible.
2. **Lab-Side Report Upload:** The blood report is generated by the laboratory after specimen analysis. The authenticated laboratory technician uploads this generated report (`.pdf`) into the active visit.
3. **Preserved Original Report:** The uploaded source document is archived without modification (`DiagnosticReport.original_file_name`, `report_source_type: 'LAB_UPLOADED_ORIGINAL'`) and linked to the cryptographic SHA-256 integrity hash.
4. **Automated Digital Extraction & Deterministic Validation:** The engine parses canonical CBC parameters, maps reference ranges, and applies deterministic reference checks (`NORMAL`, `LOW`, `HIGH`).
5. **Quality Review Gate:** Any observation flagged as `NEEDS_REVIEW` strictly blocks report publication until verified or corrected by the reviewing pathologist.
6. **Self-Terminating Bounded Access:** Upon report publication, the laboratory's access grant automatically terminates (`status: 'EXPIRED'`). There is **no manual revoke button**; access self-terminates by construction.

## 4. API Endpoints Contract (Locked)

| Method | Endpoint | Description | Invariant Enforced |
|---|---|---|---|
| `GET` | `/api/lab/list` | Returns registered laboratories | Active facility metadata |
| `GET` | `/api/lab/dashboard/:labId` | Retrieves metric counts and worklist | Redacts patient identity if grant is expired |
| `GET` | `/api/lab/grant/:grantId/patient-identity` | Retrieves the 4 identity fields | Returns `403 Forbidden` if grant is expired |
| `POST` | `/api/lab/upload-report` (or `/generate-report`) | Ingests report, preserves file name, extracts CBC | SHA-256 hash & duplicate detection |
| `GET` | `/api/lab/report/:reportId` | Retrieves structured observations | Returns locked findings if published |
| `PUT` | `/api/lab/observation/:observationId` | Pathologist corrects/confirms extracted value | Re-validates deterministically |
| `POST` | `/api/lab/report/:reportId/publish` | Seals report and locks observations | Automatically sets grant to `EXPIRED` |
| `POST` | `/api/seed/reset` | Resets demo state to fresh active Rahul Sharma visit | Sandbox repeatability |
